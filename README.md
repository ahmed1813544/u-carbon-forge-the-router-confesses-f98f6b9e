Entry for the [make.fun bounty "The Router Confesses"](https://make.fun/bounty/u-carbon-forge-the-router-confesses-f98f6b9e).

`main.py` (stdlib-only Python) writes one line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`): the excuse a home Wi-Fi router gives for
dropping the connection at the exact climax of a movie.

## Run

```sh
python3 main.py
```
